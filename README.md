# LeadFlow CRM

CRM-панель для сбора заявок из нескольких проектов: барбершопа NordCut и интернет-магазина Valery's Coffee.

## Задача проекта

Создать единый центр заявок: клиент оставляет заявку на сайте, владелец получает уведомление в Telegram, а CRM сохраняет копию заявки в базе данных и показывает общую выручку в работе.

## Как работает

1. Клиент отправляет форму на сайте NordCut или Valery's Coffee.
2. Сайт отправляет уведомление владельцу в Telegram.
3. Сайт параллельно отправляет копию заявки в LeadFlow CRM через `/api/leads`.
4. CRM сохраняет заявку в Postgres.
5. Владелец видит заявки, суммы, статусы и выручку в работе.

## Что реализовано

- Общий список заявок из подключенных проектов.
- Защищенный вход в CRM по паролю администратора.
- Kanban-воронка по статусам: новая, в работе, закрыта.
- API endpoint `/api/leads` для приема заявок.
- Ручное добавление заявок из звонков, сообщений и офлайн-обращений.
- Сохранение заявок в Postgres через `DATABASE_URL`.
- Fallback в память сервера для локального запуска без базы.
- Фильтр по проекту: NordCut, Valery's Coffee, ручная заявка.
- Фильтр по статусу заявки.
- Фильтр по оплате: все, не оплачено, оплачено.
- Фильтр по периоду: все время, сегодня, 7 дней, 30 дней.
- Фильтр по архиву: активные, архив, все.
- Поиск по клиенту, проекту и услуге.
- Карточка выбранной заявки.
- Редактирование заявки: клиент, телефон, услуга, сумма и комментарий.
- Архивирование ошибочных, тестовых и дублирующихся заявок с подтверждением.
- Быстрые действия из карточки: звонок, WhatsApp и копирование телефона.
- Быстрая смена статуса: новая, в работе, закрыта.
- Отдельный статус оплаты: не оплачено, оплачено.
- История действий по заявке: создание, смена статуса, смена оплаты.
- Ручные заметки менеджера в истории заявки.
- Следующее действие по заявке: задача и дата напоминания.
- Блок задач на сегодня и просроченных действий по клиентам.
- Контроль открытых заявок без следующего действия.
- Подсчет общего количества заявок.
- Подсчет заявок в работе.
- Подсчет выручки в работе.
- Подсчет оплаченной выручки.
- Финансовая сводка: неоплаченная сумма, средний чек и конверсия в оплату.
- Аналитика по проектам: заявки, потенциал, оплачено и конверсия.
- База клиентов с группировкой по телефону.
- Сводка по клиенту: количество заявок, активные заявки и оплаченная сумма.
- Экспорт заявок в CSV для Excel и Google Sheets.
- Адаптация под мобильные экраны.

## Переменные окружения

```env
DATABASE_URL=postgres://user:password@host/database?sslmode=require
CRM_WEBHOOK_SECRET=общий_секрет_для_подключенных_сайтов
CRM_ADMIN_PASSWORD=пароль_для_входа_в_CRM
```

`DATABASE_URL` нужен для постоянного хранения заявок. Если его нет, проект работает в демо-режиме и хранит заявки только в памяти сервера.

`CRM_WEBHOOK_SECRET` защищает API от случайных запросов. Такой же секрет нужно указать в проектах, которые отправляют заявки в CRM.

`CRM_ADMIN_PASSWORD` закрывает CRM-панель паролем. Если переменную не задавать, локально CRM откроется без входа.

## Переменные в подключенных проектах

В NordCut и Valery's Coffee нужно добавить:

```env
CRM_WEBHOOK_URL=https://ваш-домен-crm.vercel.app/api/leads
CRM_WEBHOOK_SECRET=тот_же_секрет_что_в_crm
```

## Локальный запуск

```bash
npm install
npm run dev
```

Если PowerShell блокирует `npm`, используйте:

```powershell
npm.cmd run dev -- --port 3001
```

CRM будет доступна по адресу:

```text
http://localhost:3001
```
