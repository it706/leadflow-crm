# LeadFlow CRM

Мини-CRM для учета ручных заявок, заявок с сайтов и обращений из Telegram.

Проект создан для владельцев малого бизнеса, локальных услуг, салонов, студий, интернет-магазинов и владельцев сайтов, которым нужен не просто сайт, а понятная система контроля заявок, задач, клиентов и выручки.

## Задача проекта

У бизнеса часто нет единого места, где видно:

- сколько заявок пришло;
- какие заявки новые, в работе или закрыты;
- какие заявки оплачены;
- какая выручка уже получена;
- какая сумма еще находится в работе;
- кому нужно перезвонить;
- какие задачи менеджер может упустить.

LeadFlow CRM решает эту проблему: заявки из разных источников собираются в одной панели, владелец видит статусы, оплату, задачи, клиентов, выручку и конверсию.

## Для кого

- владельцы сайтов;
- владельцы малого бизнеса;
- студии услуг;
- салоны и барбершопы;
- интернет-магазины;
- локальные бизнесы, которые получают заявки через сайт, Telegram, звонки и сообщения.

## Что умеет CRM

- Принимать заявки с подключенных сайтов.
- Принимать копии заявок после Telegram-уведомлений.
- Добавлять ручные заявки из звонков, сообщений и офлайн-обращений.
- Хранить заявки в базе данных Postgres.
- Защищать CRM входом по паролю администратора.
- Показывать kanban-воронку по статусам: новая, в работе, закрыта.
- Управлять оплатой: не оплачено, оплачено.
- Редактировать заявку: клиент, телефон, услуга, сумма и комментарий.
- Ставить следующее действие по заявке: задача, дата и точное время.
- Показывать задачи на сегодня и просроченные действия.
- Показывать заявки без следующего действия.
- Добавлять заметки менеджера в историю заявки.
- Хранить историю действий: создание, смена статуса, смена оплаты, задачи и заметки.
- Быстро звонить клиенту, открывать WhatsApp и копировать телефон.
- Архивировать ошибочные, тестовые и дублирующиеся заявки.
- Возвращать заявки из архива обратно в активную работу.
- Фильтровать заявки по проекту, статусу, оплате, периоду и архиву.
- Искать заявки по клиенту, проекту и услуге.
- Считать общее количество заявок.
- Считать заявки в работе.
- Считать выручку в работе.
- Считать оплаченную выручку.
- Показывать неоплаченную сумму, средний чек и конверсию в оплату.
- Показывать аналитику по проектам.
- Группировать клиентов по телефону.
- Показывать клиентскую базу и ценность контактов.
- Экспортировать заявки в CSV для Excel и Google Sheets.
- Работать на ПК и мобильных экранах.

## Польза для бизнеса

CRM помогает владельцу бизнеса не терять заявки, контролировать менеджера, видеть прибыль, отслеживать оплату и понимать, какие клиенты и проекты приносят деньги.

Вместо разрозненных сообщений в Telegram, звонков и таблиц бизнес получает единый рабочий экран: заявки, статусы, задачи, выручка, клиенты и отчеты.

## Как работает

1. Клиент оставляет заявку на сайте или пишет в подключенный канал.
2. Сайт отправляет уведомление владельцу в Telegram.
3. Сайт параллельно отправляет копию заявки в LeadFlow CRM через `/api/leads`.
4. CRM сохраняет заявку в Postgres.
5. Владелец видит заявку в панели, переводит ее по статусам, ставит задачи и контролирует оплату.

## Подключенные проекты

CRM может принимать заявки из нескольких проектов. В учебном портфолио подключены:

- NordCut — сайт барбершопа с записью в Telegram;
- Valery's Coffee — интернет-магазин кофе с заказами в Telegram;
- ручные заявки, которые менеджер добавляет сам.

## Переменные окружения CRM

```env
DATABASE_URL=postgres://user:password@host/database?sslmode=require
CRM_WEBHOOK_SECRET=shared_secret_for_connected_sites
CRM_ADMIN_PASSWORD=admin_password_for_crm_login
```

`DATABASE_URL` нужен для постоянного хранения заявок. Если его нет, проект работает в демо-режиме и хранит заявки только в памяти сервера.

`CRM_WEBHOOK_SECRET` защищает API от случайных запросов. Такой же секрет нужно указать в проектах, которые отправляют заявки в CRM.

`CRM_ADMIN_PASSWORD` закрывает CRM-панель паролем. Если переменную не задавать, локально CRM откроется без входа.

## Переменные в подключенных проектах

В проектах, которые отправляют заявки в CRM, нужно добавить:

```env
CRM_WEBHOOK_URL=https://your-crm-domain.vercel.app/api/leads
CRM_WEBHOOK_SECRET=same_secret_as_in_crm
```

## Локальный запуск

```bash
npm install
npm run dev
```

Если PowerShell блокирует `npm`, используйте:

```powershell
npm.cmd run dev -- --port 3001
```

CRM будет доступна по адресу:

```text
http://localhost:3001
```
